# 🤖 BCS Trading Assistant

Telegram-бот для анализа и сопровождения сделок через БКС. Проект не выполняет сделки автоматически: он ведет дневник, считает риск, комиссии, P&L, winrate и помогает разбирать торговые идеи.

> ⚠️ Это не инвестиционная рекомендация. Все торговые решения принимает пользователь.

## Что умеет бот

- Telegram Bot API и inline-кнопки в личном чате администратора.
- Дневник сделок и сопровождение открытых позиций.
- Расчет суммы позиции, риска в рублях и процентах от депозита.
- Расчет потенциальной прибыли, risk/reward, комиссий БКС и итогового P&L.
- Дневные и месячные отчеты: депозит, позиции, закрытые сделки, комиссии, winrate, лучшие/худшие сделки.
- Rule-based анализ инструмента и AI-разбор сделки без автоторговли.
- Поддержка инструментов: акции РФ, фьючерсы MOEX, валюта, облигации, фонды, опционы.

## Быстрый старт локально

```bash
npm install
cp .env.example .env
npm run build
npm start
```

Минимальный `.env`:

```env
BOT_TOKEN=telegram_bot_token
ADMIN_ID=123456789
DATABASE_URL=./bcs-trading.db
BROKER=BCS
DEFAULT_DEPOSIT_RUB=1000000
DEFAULT_RISK_PER_TRADE=1
OPENAI_API_KEY=
```

Совместимость: если уже заданы старые `TELEGRAM_BOT_TOKEN` и `TELEGRAM_ADMIN_ID`, бот тоже их прочитает. Для новой BCS-версии рекомендуется использовать `BOT_TOKEN` и `ADMIN_ID`.

## Railway deploy

1. Создайте новый репозиторий, например `bcs-bot`.
2. Залейте туда этот код.
3. В Railway добавьте сервис из GitHub-репозитория.
4. Добавьте переменные окружения:
   - `BOT_TOKEN`
   - `ADMIN_ID`
   - `DATABASE_URL` — можно оставить `./bcs-trading.db` для простого SQLite запуска
   - `BROKER=BCS`
   - `DEFAULT_DEPOSIT_RUB`
   - `DEFAULT_RISK_PER_TRADE`
5. Команда сборки: `npm run build`.
6. Команда запуска: `npm start`.

## Главное меню

Команда `/start` открывает inline-menu:

- 📊 Портфель
- 📝 Добавить сделку
- 📈 Анализ инструмента
- 🧠 AI-разбор
- ⚠️ Риск-менеджмент
- 💰 Комиссии БКС
- 📋 Дневник сделок
- 📅 Отчет за день
- 📆 Отчет за месяц
- ⚙️ Настройки

Кнопки работают только для `ADMIN_ID`. Канал для сигналов этой версии не используется: бот — аналитический помощник и дневник сделок.

## Добавление сделки

Через кнопку **📝 Добавить сделку** бот спросит:

1. тикер;
2. тип инструмента: акция / фьючерс / валюта / облигация / фонд / опцион;
3. направление LONG / SHORT;
4. цена входа;
5. количество;
6. стоп-лосс;
7. тейк-профит;
8. комиссия;
9. комментарий.

После сохранения бот покажет:

- сумму позиции;
- риск в рублях;
- риск в процентах от депозита;
- потенциальную прибыль;
- risk/reward;
- комиссию;
- решение: сделка допустима или лучше пропустить.

## Комиссии БКС

В коде есть TypeScript-модуль `src/bcs/commission.ts` и Python-зеркало `commission_bcs.py` для ручных проверок.

Настройки по умолчанию:

- обслуживание: 299 ₽/мес при наличии операций;
- ценные бумаги: 0.04% от оборота;
- валюта: 0.04% от оборота;
- покупка USD/EUR/HKD/GBP: дополнительная комиссия 0.1%;
- срочные контракты: 1.2 ₽ за контракт;
- опционы: не более 1% от объема сделки.

ENV для комиссий:

| Переменная | По умолчанию |
|---|---:|
| `BCS_MONTHLY_SERVICE_FEE` | `299` |
| `BCS_SECURITIES_FEE_PERCENT` | `0.04` |
| `BCS_CURRENCY_FEE_PERCENT` | `0.04` |
| `BCS_EXTRA_FX_BUY_FEE_PERCENT` | `0.1` |
| `BCS_FUTURES_FEE_RUB` | `1.2` |
| `BCS_OPTIONS_MAX_FEE_PERCENT` | `1` |

## Безопасность

- Автоматической торговли нет.
- Интеграции с брокерским API нет.
- Бот не выставляет заявки и не управляет счетом.
- Все решения принимает пользователь.
- В каждом аналитическом сценарии используется предупреждение: “Это не инвестиционная рекомендация”.
